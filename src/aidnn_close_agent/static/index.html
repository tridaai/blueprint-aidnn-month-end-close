What the verifier enforces

Every figure in a pack is recomputed from the source extracts by an independent code path. A figure that cannot be reproduced blocks the pack, with the variance named — a duplicated journal, an unmatched intercompany leg, a subledger tie-out gap. A pack built from superseded extracts goes stale by its version stamps and cannot be signed. Only a fully verified pack reaches the controller.
